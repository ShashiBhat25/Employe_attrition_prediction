# Employee Attrition Analytics

A machine learning system that predicts employee attrition risk, identifies key retention drivers, audits model fairness, and quantifies the financial impact — all served through an interactive Flask web dashboard.

---

## Features

- **ML Pipeline** — Trains and compares Logistic Regression, Random Forest, and XGBoost models. Handles class imbalance with SMOTE. Auto-selects the best model by recall.
- **Risk Tiering** — Scores every employee as Critical / High / Medium / Low with a recommended HR action for each tier.
- **Feature Importance** — Shows the top drivers of attrition (overtime, satisfaction scores, income, stagnation, etc.).
- **Fairness Audit** — Evaluates demographic parity and equalized odds across Gender and Age groups using Fairlearn.
- **ROI Calculator** — Estimates cost of attrition vs. cost of intervention so HR can justify budget decisions.
- **Individual Prediction** — Enter any employee's profile and get an instant attrition probability with a gauge chart.
- **Interactive Dashboard** — Built with Flask + Plotly; includes heatmaps, bar charts, waterfall charts, and downloadable reports.

## Quick Start

**1. Install dependencies**
```bash
pip install -r requirements.txt
```

**2. Run the ML pipeline**
```bash
python src/pipeline.py data/WA_Fn-UseC_-HR-Employee-Attrition.csv
```
This generates all model artifacts under `artifacts/`.

**3. Launch the dashboard**
```bash
python app/app.py
```
Open `http://localhost:5000` in your browser.
